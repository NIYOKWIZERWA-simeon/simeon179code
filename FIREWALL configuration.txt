==============================================================
object network dmz-server

access-list OUTSIDE-DMZ permit icmp any host 192.168.2.3

==============================================

 Define the IPsec transform set (Phase 2)
=========================================

Routers configured: SITE1, SITE2. The command is identical on both routers.

configure terminal
crypto ipsec transform-set VPN-SET esp-aes 256 esp-sha-hmac
end

 Create the access list
=========================
Routers configured: SITE1, SITE2. The access list selects the traffic to protect and must be a mirror image
on the two routers.

SITE1

configure terminal
access-list 110 permit ip 192.168.10.0 0.0.0.255 192.168.20.0 0.0.0.255
end

SITE2

configure terminal
access-list 110 permit ip 192.168.20.0 0.0.0.255 192.168.10.0 0.0.0.255
end

 Create the crypto map for IPsec
==============================
Routers configured: SITE1, SITE2.

SITE1

configure terminal
crypto map VPN-MAP 10 ipsec-isakmp
set peer 20.20.20.2
set transform-set VPN-SET
match address 110
exit
end

SITE2

configure terminal
crypto map VPN-MAP 10 ipsec-isakmp
set peer 10.10.10.2
set transform-set VPN-SET
match address 110
exit
end

 Apply the crypto map to the outgoing interface
===================================================
Routers configured: SITE1, SITE2. The map is applied to the serial interface that faces the ISP.

SITE1 and SITE2 (same commands)

site1

configure terminal
interface serial 0/1/0
crypto map VPN-MAP
exit
end
write memory

site2
 
configure terminal
interface serial 0/0/1
crypto map VPN-MAP
exit
end
write memory
